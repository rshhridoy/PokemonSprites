# ⚡ Pokedex

A simple and interactive **Pokedex** built using **HTML, CSS, and JavaScript**. This application allows users to search for a Pokémon by name and retrieve its sprite image and primary type using the [PokéAPI](https://pokeapi.co/).

Enter a Pokémon's name, click the **Fetch Pokémon** button, and view its information in a styled Pokémon card.

## 🎮 Pokémon Search

Search for your favorite Pokémon by entering its name.

Examples:

- ⚡ Pikachu
- 🔥 Charizard
- 💧 Squirtle
- 🌿 Bulbasaur
- 👻 Gengar

The application fetches Pokémon data from the API and dynamically displays its sprite image and primary type.

## ✨ Features

- 🔍 Search Pokémon by name
- 🖼️ Display Pokémon sprite images
- 🏷️ Show the Pokémon's primary type
- 🌐 Fetch Pokémon data using PokéAPI
- ⚡ Asynchronous API requests using `async/await`
- ⚠️ Display error messages for invalid Pokémon names
- 🎨 Styled Pokémon card interface
- 🖱️ Interactive search button
- 🔄 Dynamically update Pokémon information
- 🧩 Built with vanilla JavaScript — no frameworks or libraries
- 🔑 No API key required

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Card styling, layout, colors, and visual design
- **JavaScript (ES6)** — Application logic and DOM manipulation
- **Fetch API** — Retrieve data from an external API
- **PokéAPI** — Provide Pokémon information and sprite images

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/rshhridoy/Pokedex.git
```

### 2. Navigate to the project folder

```bash
cd Pokedex
```

### 3. Open the project

Open `index.html` in your browser, or use the **Live Server** extension in VS Code to run the application locally.

### 4. Search for a Pokémon

1. Enter a Pokémon name in the input field.
2. Click the **Fetch Pokémon** button.
3. View the Pokémon's sprite image and primary type.

**Note:** An active internet connection is required to retrieve Pokémon data from PokéAPI.
